# AI 작업 도우미

작업할 폴더를 고르고, GPT(Codex) 나 Claude(Claude Code)에게 **말로 일을 시키는** 프로그램입니다.
폴더 안 파일을 읽고 정리하거나, 엑셀·문서를 고쳐 줍니다. 자주 쓰는 말은 프롬프트로 저장해 두고 누르기만 하면 됩니다.

## 내려받기

### [AI 작업 도우미 내려받기 (ai-helper.zip)](https://github.com/hfoodlabmarketing/hfoodlab_program/releases/download/ai-helper/ai-helper.zip)

파이썬 같은 프로그램을 따로 깔 필요가 없습니다.

## 처음 쓸 때

1. 받은 `ai-helper.zip` 을 **압축 풀기** 합니다.
2. 풀린 `AI 작업 도우미` 폴더에서 **`AI 작업 도우미.exe`** 를 더블클릭합니다.
   처음 한 번 바탕화면에 「AI 작업 도우미」 바로가기가 생기고, 다음부터는 그걸로 켭니다.
3. **계정** 줄에서 `[설치]` → `[연결]` 을 누릅니다. 「회의 메모 정리」에서 이미 했다면 그대로 연결돼 있습니다.
4. **작업 폴더**를 고르고(`[찾아보기]` 또는 경로 붙여 넣기), 아래 칸에 시킬 일을 적고 Enter 를 누릅니다.

## 알아 둘 것

- AI 가 작업 폴더 안의 파일(엑셀 포함)을 **직접 고칠 수 있습니다.** 폴더마다 처음 한 번 확인 창이 뜹니다.
  중요한 파일은 따로 백업해 두세요.
- GPT(Codex)는 윈도우 보호 장치로 작업 폴더 밖 파일을 고치지 못합니다.
  Claude 는 작업 폴더 안 파일 고치기와 `python` 실행만 허용합니다.
- 드라이브 전체(`C:\` 등)나 사용자 폴더 전체는 작업 폴더로 고를 수 없습니다.
- 대화는 이어서 할 수 있습니다. 폴더나 AI 를 바꾸려면 `[새 대화]` 를 누릅니다. 프로그램을 닫으면 대화는 남지 않습니다.
- 일하는 도중 `[중지]` 를 누르면 멈춥니다. 그때까지 고친 파일은 되돌려지지 않습니다.
- 프롬프트는 이 PC 에만 저장됩니다.

## 고치는 사람에게

- 파이썬이 있는 PC 에서는 `pythonw ai_helper.py` 로 바로 켭니다.
- 배포판은 `python build.py` 로 만들고(`dist/ai-helper.zip`), Release `ai-helper` 의 파일을 이것으로 바꿉니다.
