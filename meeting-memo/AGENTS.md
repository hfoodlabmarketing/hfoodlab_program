# 회의록 정리 방식

이 폴더에서 받는 요청은 전부 **회의 메모를 회의록으로 정리**하는 일이다.
Codex 는 이 파일을, Claude Code 는 CLAUDE.md 를 거쳐 이 파일을 읽는다 — 정리 방식을 바꾸려면 이 파일만 고친다.

## 순서

1. **요약** — 맨 위 `## 요약` 아래 3~5줄. 무엇을 정했고 무엇이 남았는지.
2. **※ 공통 사항** — 요약 바로 아래. 한 주제가 아니라 회의 전체에 걸리는 강조·원칙·같이 정할 것을
   `※` 로 한 줄씩. 없으면 쓰지 않는다.
3. **체크리스트** — `## 체크리스트` 아래에 주제별로 나눈다. 주제와 주제 사이는 `---`.

## 체크리스트 쓰는 법

- 주제 제목은 `**[메인 페이지]**` 처럼 굵은 대괄호로 쓰고, 메모에 나온 순서를 따른다.
- 체크박스는 **할 일·확인할 것·정한 항목**에만 쓴다. 모든 줄을 체크박스로 만들지 않는다.
  - `- [x]` — 메모에 완료·확정·했음·OK 처럼 끝났다는 말이 있을 때만
  - `- [ ]` — 그 밖의 전부(해야 할 것·아직·확인 필요)
- 이유·세부 내용·의견은 그 항목 아래에 두 칸 들여 쓴 일반 불릿으로 붙인다(체크박스 없이).
- 진행 결과·공유 상태는 빈 줄 뒤에 `→` 로 시작하는 줄로 쓴다. 예: `→ 연구전담부서 공유 완료`
- 담당자는 메모에 있을 때만 항목 끝에 `@이름`. 다른 팀에 물어야 하면 `(영업지원팀 문의 필요)` 처럼 괄호로.

## 문장

- 짧은 명사형으로 끝낸다 — `~ 필요`, `~ 예정`, `~ 세팅`, `~ 확인`, `~ 요청`, `~ 완료`.
- 숫자·이름·제품명·인증명 같은 구체적인 값은 메모 그대로 살린다.
- 메모에 없는 내용·담당자·기한을 지어내지 않는다.
- 회의가 진행 중일 수 있다. 메모가 짧거나 끊겨 있어도 있는 만큼만 정리한다.
- 맨 위 제목(`#`)과 일정은 쓰지 않는다 — 프로그램이 붙인다.

## 예시

양식만 따른다(내용은 예시다).

```markdown
## 요약
- 메인·결제 화면은 대부분 확정, 소식 영역·쿠폰가 노출은 남음
- 상세 페이지는 글꼴부터 바꾸기로 함

※ 모바일 화면을 기준으로 잡고 PC 는 맞춰 가기로 함
※ 검색 노출을 위해 이미지 대신 글자로 넣을 수 있는 건 글자로 세팅 필요

## 체크리스트

**[메인 페이지]**

- [x] 카테고리 바
- [ ] 소식 영역(이벤트/뉴스/칼럼)
  - 카테고리 → 게시글로 두 번 눌러야 해서 소비자가 안 누를 수 있어 개선 필요
- [ ] SNS 위젯 @김담당
  - 국내 계정 외 해외 계정까지 나라별로 등록 필요

---

**[상품 상세 페이지]**

- [x] 쇼핑몰 결에 맞게 상세 페이지 변경 예정(글꼴 우선)

→ 디자인팀 공유 완료

---

**[자주 묻는 질문]**

- [x] 1:1 문의는 무조건 비밀글로 잠기게 개발
- [ ] 바로 질문하기 → 채팅 상담 연결 가능 여부 (고객지원팀 문의 필요)
```
